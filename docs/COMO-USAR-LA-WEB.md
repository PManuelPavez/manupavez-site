# 🎯 CÓMO USAR TU WEB PARA CERRAR GIGS

Guía práctica y accionable. **Objetivo único**: gigs en Argentina + LATAM + Rio de Janeiro (enero).

---

## PARTE 1 · CÓMO FUNCIONA LA WEB HOY

Tu home es una **página landing booker-first**. Cada bloque tiene un rol específico en la conversión de un promoter:

| Bloque | Rol | Qué venden |
|---|---|---|
| **Hero** | Impacto inmediato · foto + nombre + redes + botón BOOKING | Ficha de identidad. En 3 segundos el promoter sabe quién sos y cómo bookearte. |
| **Stats / En Números** | Prueba dura (Spotify, seguidores, releases) | Escala numérica |
| **Credenciales (Sellos + Shared Stage + Support)** | Prueba social HARD | Es tu credencial más fuerte. **Nick Warren + Sahar Z apoyaron tu sonido** es el argumento #1. |
| **Música · Diarios** | Discografía · slider Apple-grade | Muestra volumen + calidad de release |
| **Sets** (Live Sets) | 4 videos reales tocando | Prueba de que **existís en cabina**, no solo en estudio |
| **En Vivo** | Próximas fechas | Actividad viva |
| **Booking** | Form + pitch | **El punto de conversión.** Warm-ups y Opening Sets · 200 USD · 3 CDJs |
| **Lab (compacto)** | Link a `/clinicas.html` | Secundario — sin real estate innecesario |
| **Instagram** | Prueba de audiencia activa | Muestra que tenés circulación |

**Flujo mental de un promoter que llega**:
> Hero (¿quién?) → Credenciales (¿es real?) → Música/Sets (¿suena bien?) → Booking (¿cómo lo contrato?)

Ese flujo se recorre en **~40 segundos**. Si el promoter no clickea BOOKING antes de ese tiempo, perdiste la venta. La web está diseñada para acortar esos 40 segundos.

## PARTE 5 · REGLAS DE ORO

1. **La web no te consigue gigs sola.** La web CIERRA los gigs que vos empezás por DM/mail. Sin outreach outbound sistemático, la web es un CV lindo.

2. **1 mensaje/día es intocable.** 30 mensajes al mes = 3-5 respuestas = 1-2 fechas cerradas. Matemática básica.

3. **Nunca mandes un mensaje sin un asset.** Adjuntá siempre: link al set + link a la web + presskit. Sin eso, el promoter no tiene qué evaluar.

4. **Follow-up a los 7 días.** Si no respondieron, mandá algo corto: "¿pudiste ver mi propuesta anterior? Sigo con la fecha disponible". La mitad de los cierres pasan en el follow-up, no en el primer contacto.

5. **Aprovechá viajes personales.** Rio en enero → cerrás fecha allá pagándote parte del viaje. Cualquier otro viaje personal futuro es una oportunidad de gig.

6. **La web es un espejo de tu tracción.** Actualizala cuando pase algo (nueva fecha cerrada, release nuevo, apoyo grande). Un promoter que vuelve a mirarla en 2 meses tiene que ver movimiento.

## PARTE 6 · SEÑALES DE ÉXITO A 90 DÍAS

Sabés que la estrategia está funcionando cuando:

- [ ] Cerraste **al menos 3 fechas nuevas** (no repetidas de venues ya tocados)
- [ ] Al menos **1 fecha fuera de Argentina** (Rio, Uruguay, Chile)
- [ ] Al menos **1 warm-up de artista tier internacional**
- [ ] Tenés **10+ contactos activos** en negociación (aunque no cerrados)
- [ ] Tu Instagram creció por venir de esas fechas (tag + repost del venue)

Si a los 90 días no ves 3 de esos 5 checks → el problema no es la web, es el **volumen del outreach**. Duplicalo.
